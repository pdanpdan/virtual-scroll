Virtual Scroll Comparison

@pdanpdan/virtual-scroll and seven other Vue 3 virtualization libraries. Versions, publish dates, star counts and bundle sizes were checked on 2026-10-29. This package's row is measured from its build on every docs build.

This page compares the Vue 3 packages that virtualize lists and grids: which features each one includes, what an entry costs in bytes, and how the APIs differ. The feature matrix is the only place where a support level is stated.

The table covers this package, vue-virtual-scroller, @tanstack/vue-virtual, virtua, vueuc, vue-virtual-scroll-list, @ceriousdevtech/vue-cerious-scroll and vlist.

Notes on the Partial Marks

🟠
@tanstack/vue-virtual

Headless: it provides the virtualizer and the application writes the markup, so every row not listed as ✅ is code you add. A two-axis grid is composed from two virtualizers, RTL is an isRtl flag, and scrollbars and snapping are not included. The entry is among the smallest here.

🟠
virtua

VGrid virtualizes both axes and VMasonry covers masonry; its README lists sticky headers and keyboard navigation as planned. Window scrolling and measured sizes are supported. One codebase serves five frameworks.

🟠
vue-virtual-scroll-list

Sizes come from an estimate cache (estimate-size) instead of measurement, so scrollbar accuracy is approximate. The last release dates from May 2023, the README targets Vue 2, and the package ships no TypeScript types.

🟠
vue-virtual-scroller

Infinite loading requires your own scroll listener. The component renders its own scroll container, so page scrolling needs a wrapper. Version 3.0 is maintained; the feature set is close to the Vue 2 version.

🟠
vueuc

VVirtualList is the list used by Naive UI. The author describes vueuc as a personal utility collection, so adopting it means depending on Naive UI's internal packages.

🟠
@ceriousdevtech/vue-cerious-scroll

It measures rows and includes masonry and real table layouts. Infinite loading is manual: detect the end, append, call updateTotalElements and re-render. It does not use the browser scrollport for input: wheel, touch and keyboard are handled on a hidden-overflow host. Horizontal lists, grids and sticky headers are listed as future work in its roadmap.

🟠
vlist

The grid is a single-axis layout: columns and a gap over a vertical list. Snapping is part of the carousel plugin. RTL covers vertical lists and tables; horizontal lists throw at creation. Prepending holds the visible rows in place only in reverse mode. The table renders div rows with resizable columns, and rows must exist as an array. The entry is vlist/vue over the core with plugins imported per feature; vlist/config, used by the deprecated adapters, imports every plugin and has its own row.

When to Choose Each One

  • @pdanpdan/virtual-scroll - the only entry here that combines a two-dimensional grid, window scrolling, RTL, sticky headers and keyboard navigation in one component, and the only one with a dedicated real-table-flow component. It also ships masonry, and with vlist it is one of two entries that virtualize past the browser's maximum element height. Index-only rows, ARIA roles, virtual scrollbars and a headless composable with extensions are included. The bundle is larger than the single-purpose libraries: 23.4 kB gzip for the package root and 18.0 kB for the lean /core component. The headless engine is 10.9 kB, 13.8 kB with the observer, keyboard and scrollbar composables, and 16.5 kB with every exported extension. Per kB gzip the single-purpose libraries lead (virtua 6.3, @tanstack/vue-virtual 2.7). The project is young and has a small community.
  • @ceriousdevtech/vue-cerious-scroll - the only other entry with real table rows; it also includes masonry and keyboard navigation. It is vertical only: no grid, horizontal mode, window scrolling, RTL, sticky, snapping, SSR or beyond-max support, and input is handled on a hidden-overflow host rather than the browser scrollport. At 26.7 kB gzip it is the largest default entry here.
  • vlist - a framework-agnostic core with Vue, React, Svelte and Solid entries and plugins for grid, masonry, table, tree, groups, selection, search, sortable, snapshots, transition, carousel and async data. With plugins imported per feature the core is 12.8 kB gzip, 15.7 kB with the scrollbar plugin; document scrolling is a plugin, the custom scrollbar is an overlay, and scroll.mode hands a list to a synthetic driver when it passes the browser's size limit. It has no two-dimensional grid, no horizontal RTL, no snapping outside the carousel, no real table rows and no forward-list prepend anchoring. First released this year.
  • vue-virtual-scroller - a conventional component API with a long release history. Window scrolling, RTL and two-dimensional layouts are not included.
  • @tanstack/vue-virtual - a plain list with full control of the markup, in the smallest bundle here. Grid, scrollbar and snapping code is yours to write.
  • virtua - small bundles, window scrolling, measured sizes, a two-dimensional grid and masonry. Sticky headers and keyboard navigation are planned, not shipped.
  • vueuc - VVirtualList is the list used by Naive UI; it is a reasonable choice inside that ecosystem.
  • vue-virtual-scroll-list - last released in May 2023; sizes are estimates rather than measurements.

Bottom Line

Any of these libraries handles a vertical list with known row sizes. The differences appear with a second axis, the page as the scroll container, sticky headers, keyboard support, or lists larger than the browser's height limit. The feature matrix shows which entry covers each case, and the size columns show what it costs.
