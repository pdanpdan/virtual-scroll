Virtual Scroll

Stand-alone UMD Examples

Grid Dynamic

Rows and columns virtualized at once, with column widths read from the DOM.

Grid Fixed

Rows and columns virtualized at once with a fixed itemSize and alternating columnWidth values.

Horizontal Dynamic

Horizontal list of items whose widths are measured with ResizeObserver.

Horizontal Fixed

Horizontal list of uniform-width items, with the row height filled automatically.

Vertical Dynamic

Vertical list of variable-height rows, measured with ResizeObserver.

Vertical Fixed

Vertical list of uniform-height rows; only the rows in the viewport are rendered.

Custom Scrollbar

Virtual scrollbars drawn inside the container, styled with CSS variables or your own markup.

Infinite Scroll

Automatic pagination with the load event and the loading slot.

Sticky Sections

Section headers that stick to the top and get pushed out by the next one.

Chat Interface

Chat with bubble heights measured from the DOM, opening at the bottom, and history loading without moving the view.

Table

Virtualized rows in real table markup, for accessible tabular data.
